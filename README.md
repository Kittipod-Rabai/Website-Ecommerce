# Maison Fleur — เว็บขายดอกไม้

เว็บอีคอมเมิร์ซร้านดอกไม้ เลือกวัน-เวลาจัดส่งได้ มีตะกร้า ชำระเงิน และแดชบอร์ดฝั่งผู้ขาย

## ลิงก์เว็บไซต์

<https://maison-fleur.onrender.com>

## บัญชีทดสอบ

| บทบาท | อีเมล | รหัสผ่าน |
|---|---|---|
| แอดมิน | `admin@maisonfleur.test` | `admin1234` |
| ลูกค้า | `customer@maisonfleur.test` | `customer1234` |

## ระบบแอดมิน (ผู้ขาย)

- ภาพรวมยอดขายและกราฟรายได้
- จัดการออเดอร์และปฏิทินจัดส่ง
- จัดการสินค้าและรูปภาพ
- ดูรายชื่อลูกค้า
- ตั้งค่าคิวต่อวัน โซนและค่าจัดส่ง
- จัดการบัญชีแอดมิน

## โครงสร้างโปรเจกต์

- `shop/app/(store)` หน้าร้านฝั่งลูกค้า
- `shop/app/admin` แดชบอร์ดฝั่งผู้ขาย
- `shop/lib` ตรรกะหลัก (การจัดส่ง ออเดอร์ การชำระเงิน)
- `shop/prisma` โครงสร้างฐานข้อมูลและข้อมูลตั้งต้น
